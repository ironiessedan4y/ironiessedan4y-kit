# ironiessedan4y-kit

Validate JSON files and print a normalized form.

Small, dependency-free Python utility package generated for day-to-day file chores.
Standard library only — no third-party imports.

## Install

```bash
pip install -e .
```

## Usage

```bash
python -m ironiessedan4y_kit.cli --help
```

```python
from ironiessedan4y_kit.core import Ironiessedan4yTool

tool = Ironiessedan4yTool()
print(tool)
```
